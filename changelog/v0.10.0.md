v0.10.0 — 2026-10-07

A mobile layout overhaul across the dashboard, refreshed contributor insights, and more reliable source health checks.

Added
- Show the current app version beside Changelog in the sidebar.
- Add mobile navigation and download drawers with shared sidebar behavior, keyboard dismissal, and reduced-motion support.
- Animate the mobile date selectors into the fixed header while scrolling, keeping the selected range visible. Tap the badge or return to the top to expand the row without changing the page's scroll position.
- Add screenshot and interaction regression checks across all 11 page routes, including phone, landscape, and desktop layouts.

Changed
- Refresh the contributors page with failure coverage summaries, a stacked activity timeline, a searchable and sortable contributor list, and group/category drill-down for every contributor.
- Add contributor refresh and retry controls, with clear loading and empty states and consistent light/dark styling.
- Let contributors and failure analytics use the full page width, and increase text and chart label sizes for readability.
- Adapt every page for phones with compact headers, mobile test and contributor cards, responsive charts, and dialogs and popovers that fit smaller screens. Preserve the existing desktop layouts.
- Replace mobile navigation with a narrow, single-column sidebar that fits short viewports without scrolling. Use compact account, timezone, and theme controls, and remove the redundant settings menu.
- Keep mobile serial search full width and place result, category, firmware, optional station, and More dropdowns in one row. More contains mode and date-link controls, plus a date picker when table dates are set separately.
- Increase the size of the selected date badge in the mobile header and keep the comparison note on one line to reduce the gap above the charts.

Fixed
- Prevent false source-unreachable alarms on large cloud-mounted directories by allowing source probes 2.5 seconds. Keep local file and lock checks at 400 milliseconds, retain the real directory-read credential check, and distinguish timeouts from filesystem errors.
- Keep Custom the same size as the other mobile date selectors, and smooth navigation and date-row animations.
- Remove the flicker at the end of the mobile date animation by keeping the selected pill visible throughout the transition.
