v0.8.0 — 2026-10-01

Work since 0.7.0. The dashboard and Failure Analytics share one period, the charts and filters were rebuilt, and stations can deliver a finished run over HTTPS.

Added
- Failure Analytics. Failure rate, test volume, and stacked history by category and by group. Opening a group filters the category ranking and the category history. Rate is a volume-weighted moving average, or a rolling window of the last 10 to 2000 tests. Percentages use failed tests or all tests as the denominator.
- Dashboard failure-rate strip and pass/fail volume on the same buckets. Buckets run from days through years. Clicking the plot sets the table dates. The pass series becomes a line once the chart is dense.
- One period on the dashboard and Failure Analytics: 7, 30, and 90 days, all time, or a custom UTC range. Latest keeps one PASS or FAIL per inverter. All tests counts every PASS and FAIL.
- Test-table filters for serial, verdict, annotation category, any tagged test, firmware, station, and date. Categories show a coloured icon and a short label. Each row shows that serial's test sequence.
- RETEST as a verdict, with a history of status overrides. Rates, summaries, and latest-per-inverter selection ignore INVALID and RETEST.
- Dark mode. Theme and sidebar behaviour live in Settings. Charts can omit days that had no tests.
- Annotation backup and restore.
- HTTPS ingest for one inverter per request, with per-station HMAC. A station can be enabled or disabled, enroll with a bootstrap token, and receive a server-assigned id. Display names stay in the browser.
- This changelog. A release note is the annotated tag message.

Changed
- The test record uses a denser header, restyled trace charts, and a compact annotation panel.
- Contributors and the untagged review queue use the same period language as the dashboard.

Fixed
- Opening a failure group updates the category ranking and the category history. The failure-rate, volume, and group-history charts stay still.
- Tooltips and labels match the charts and controls on the page.
